# EL PLAN — Precuela 8-bit de "El Escape"

Juego 8-bit hecho para la **GTA VI Marathon de KazooGod02**. Cuenta los 21 días antes del trailer "El Escape": cómo Kazoo, Coqui y Ghenghis planearon el atraco al Banco Federal de Puerto Vicio.

**Jugar:** https://kazoogod02.github.io/el-plan-gta6/

- Mundo libre visto desde arriba (estilo GTA 1/2) y interiores de lado.
- Prólogo + 9 capítulos, minijuegos, radio, teléfono, estrellas de búsqueda, coleccionables, logros y trucos.
- Funciona en PC (teclado/control) y celular (controles táctiles).

## Controles
| Acción | Teclado | Control |
|---|---|---|
| Mover / manejar | WASD o flechas | Stick |
| Acción / hablar / subir al carro | E / Enter | A |
| Golpe / disparo / freno de mano | Espacio / J | X |
| Correr / claxon | Shift | LT |
| Cambiar arma / radio | Q | RB |
| Teléfono | Tab / T | Y |
| Pausa | Esc / P | Start |

## Configurar el marathon
Edita `js/config.js`: fecha del marathon, link del stream, hashtag y capítulos por fecha (lanzamiento por episodios).
